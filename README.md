## Présentation

Ce dépôt a été réalisé dans le cadre du cours de **Programmation pour la Cybersécurité**.

L'objectif de ce travail est de comprendre plusieurs concepts fondamentaux de la sécurité réseau à travers des programmes Python illustrant le fonctionnement des protocoles étudiés durant les travaux pratiques.

Les notions abordées comprennent :

* L'analyse du trafic réseau ;
* Le fonctionnement du protocole DNS ;
* Le rôle du protocole ARP dans un réseau local ;
* Les bonnes pratiques de sécurité réseau ;
* L'importance du chiffrement et de la segmentation réseau.

---

## Structure du Projet

### analyse_reseau.py

Ce programme présente une illustration simplifiée de l'analyse d'événements réseau.

Fonctionnalités :

* Affichage des protocoles observés ;
* Affichage des adresses IP source et destination ;
* Présentation chronologique des échanges.

---

### analyse_dns.py

Ce programme illustre le principe de résolution de noms DNS.

Fonctionnalités :

* Association entre un nom de domaine et une adresse IP ;
* Consultation d'enregistrements DNS prédéfinis ;
* Compréhension du rôle du DNS dans les réseaux informatiques.

---

### analyse_arp.py

Ce programme présente une représentation simplifiée d'une table ARP.

Fonctionnalités :

* Correspondance entre adresses IP et adresses MAC ;
* Illustration du fonctionnement de la résolution d'adresses dans un réseau local ;
* Compréhension des mécanismes de communication de couche 2.

---

## Concepts étudiés

Les travaux réalisés permettent d'approfondir :

* Les protocoles TCP/IP ;
* Le modèle OSI ;
* Le protocole DNS ;
* Le protocole ARP ;
* L'administration et la sécurité des réseaux.

---

## Exécution des programmes

Ouvrir un terminal dans le dossier du projet puis exécuter :

```bash
python analyse_reseau.py
python analyse_dns.py
python analyse_arp.py
```
